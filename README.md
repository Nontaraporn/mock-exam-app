# Mock Exam App

## Tech Stack
- Frontend: Angular
- Backend: .NET 8 (C#)
- Database: SQLite

## Features
- Take a 10-question quiz
- Save scores to the database
- Display the quiz results
- View user exam history

## Run

### Backend
```cd backend/MockTest```
```dotnet run```

### Frontend
```cd frontend```
```npm install```
```npm run dev```
